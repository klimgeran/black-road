# Black Road

Side-view motorcycle stunt game. Manila, Lagos, and Moscow — ten roads each.

## How to ride

- **Gas** (right side, or D / → / W): accelerate. Hold it and the front wheel climbs. Hold it too long and the bike loops.
- **Brake** (left side, or A / ← / S): stop. Keep holding and the bike rolls backward.
- **In the air:** gas backflips, brake frontflips. Land on the wheels.
- **Red can:** fuel.
- **Blue ozone:** a hard speed kick. These sit in front of the big jumps and walls.
- Coins pay for bikes and the shop. Your best run stays on this device.

## Run it

```bash
npm install
npm run dev
```

Then open the local dev URL the script prints.
